# Changelog

## 1.2.0

- Renamed the project to Downix.
- Added Spanish and English interfaces with persistent language selection.
- Added automatic `Download/Downix/Music` and `Download/Downix/Video` folders.
- Added selectable MP3 and MP4 quality levels.
- Added Android file-explorer integration.
- Added dependency updates from the main menu.
- Added a fixed-width Termux wordmark and responsive Linux banner.
- Added automatic cleanup for standalone Termux installations.
- Added MIT licensing, copyright attribution, and third-party notices.
- Added a GitHub cover and project presentation.
